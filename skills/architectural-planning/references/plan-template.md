# Шаблон `/docs/Plan.md`

План — договор с пользователем о том, что будет сделано, и вход для `code`. Пишется для 🟡 и 🔴, утверждается до реализации.

Секции берутся по сложности: 🟡 — цель, решение, скоуп, изменения, порядок, критерии приёмки. 🔴 — плюс альтернативы, риски, откат.

Заполненная секция меняет чьё-то решение. Пустая — удаляется, а не остаётся с прочерком.
