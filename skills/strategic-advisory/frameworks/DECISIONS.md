# ПРИНЦИПЫ DALIO

## 1. Радикальная правда (Radical Truth)

**Суть:** Реальность важнее твоего эго. Боль правды сейчас < боль ошибки потом.

**Применение:**
- Не обманывай себя
- Ищи людей, которые скажут неприятное
- «Какова вероятность, что я ошибаюсь?»

## 2. Радикальная прозрачность (Radical Transparency)

**Суть:** Скрытая информация = плохие решения. Делись контекстом.

**Применение:**
- В команде: все видят всё (кроме личного)
- В анализе: показывай рассуждения, не только выводы

## 3. Меритократия идей (Idea Meritocracy)

**Суть:** Побеждает лучшая идея, не громкий голос и не должность.

**Но:** Не все мнения равны. Вес мнения = track record в этой области.

**Believability Weighting:**
```
Мнение эксперта с успешным опытом = 10 баллов
Мнение умного новичка = 3 балла
Мнение случайного человека = 1 балл
```

## 4. Pain + Reflection = Progress

**Цикл:**
```
СОБЫТИЕ (особенно болезненное)
    ↓
БОЛЬ / ДИСКОМФОРТ
    ↓
РЕФЛЕКСИЯ: Что произошло? Почему? Какой принцип нарушен?
    ↓
ПРИНЦИП: В ситуации типа X делай Y
    ↓
ИЗМЕНЕНИЕ СИСТЕМЫ / ПОВЕДЕНИЯ
    ↓
НОВОЕ СОБЫТИЕ (проверка)
```

## 5. Алгоритмизация

**Суть:** Если ситуация повторилась дважды — напиши для неё алгоритм.

**Примеры:**
- Чек-лист перед встречей
- Критерии найма
- Протокол принятия инвестиционного решения

# ПРОТОКОЛ ПРИНЯТИЯ РЕШЕНИЙ

## Шаг 1: Определи тип решения

| Тип | Характеристики | Подход |
|:----|:---------------|:-------|
| **Обратимое** | Можно откатить, низкая цена ошибки | Быстро, интуиция ОК |
| **Необратимое** | Нельзя откатить, высокая цена ошибки | Медленно, системный анализ |
| **Повторяющееся** | Типовая ситуация | Алгоритм/чек-лист |
| **Уникальное** | Новая ситуация | Первые принципы |

## Шаг 2: Собери информацию

1. Какие факты я знаю точно?
2. Какие предположения делаю?
3. Что мне нужно узнать дополнительно?
4. Кто компетентен в этой области? (Believability)
5. Какой информации мне не хватает?

## Шаг 3: Генерируй варианты

- Не останавливайся на первом варианте
- Минимум 3 альтернативы
- Включи «ничего не делать» как вариант
- Спроси: «Что бы посоветовал умный человек, который не я?»

## Шаг 4: Оцени варианты

| Вариант | Upside | Downside | Вероятность успеха | Обратимость |
|:--------|:-------|:---------|:-------------------|:------------|
| A       |        |          |                    |             |
| B       |        |          |                    |             |
| C       |        |          |                    |             |

## Шаг 5: Проверь на искажения

**Частые когнитивные искажения:**

| Искажение | Что это | Противоядие |
|:----------|:--------|:------------|
| **Confirmation bias** | Ищу подтверждение своей идеи | «Как бы я опроверг это?» |
| **Sunk cost fallacy** | Продолжаю из-за уже вложенного | «Если бы начинал с нуля, выбрал бы это?» |
| **Availability bias** | Переоцениваю то, что легко вспомнить | «Это действительно частое или просто яркое?» |
| **Overconfidence** | Переоцениваю свои способности | «Какова база успеха?» |
| **Loss aversion** | Боюсь потерь больше, чем ценю выигрыш | «Что если это возможность, а не угроза?» |

# МЕНТАЛЬНЫЕ МОДЕЛИ (от Munger)

## Инверсия
Вместо «Как достичь успеха?» спроси «Как гарантированно провалиться?» и избегай этого.

## Круг компетенции
Знай границы своего знания. Внутри круга — действуй уверенно. За пределами — ищи экспертов.

## First Principles
Разбери проблему до базовых истин, не полагайся на аналогии.

**Пример:**
- Аналогия: «Батареи дорогие, потому что всегда были дорогие»
- First principles: «Из чего батарея? Сколько стоят материалы? Почему сборка дорогая?»

## Opportunity Cost
Выбирая X, ты автоматически отказываешься от Y. Всегда спрашивай: «Что я НЕ делаю, выбирая это?»

# ЭВРИСТИКИ ДЛЯ БЫСТРЫХ РЕШЕНИЙ

Когда нет времени на полный анализ:

| Эвристика | Когда использовать |
|:----------|:-------------------|
| **Regret Minimization** | Что я буду сожалеть через 10 лет, что НЕ сделал? |
| **10/10/10** | Как я буду относиться к этому через 10 минут / 10 месяцев / 10 лет? |
| **Reversibility** | Обратимо? → Быстро. Необратимо? → Медленно. |
| **Default to Action** | При прочих равных — действуй |
| **Skin in the Game** | Что советует тот, кто теряет вместе со мной? |

# ГРУППОВЫЕ РЕШЕНИЯ

## Как избежать группового мышления

1. **Лидер высказывается последним** (иначе все подстраиваются)
2. **Назначь Devil's Advocate** (кто-то обязан критиковать)
3. **Анонимное голосование** (перед обсуждением)
4. **Пригласи внешнего** (свежий взгляд)

## Протокол группового решения

```
1. Молчаливое генерирование идей (5 мин)
2. Каждый озвучивает без обсуждения
3. Прояснение (вопросы, не критика)
4. Критический анализ (Devil's Advocate)
5. Believability-weighted vote
6. Решение принимает ответственный
