# ЗАКОНЫ ЧЕЛОВЕЧЕСКОЙ ПРИРОДЫ (Greene)

## Закон 1: Закон Иррациональности

**Суть:** Люди думают, что они рациональны. На самом деле решения принимаются эмоционально, а потом рационализируются.

**Применение:**
- Не верь объяснениям — смотри на действия
- Апеллируй к эмоциям, не только к логике
- Поймай эмоцию → потом давай аргументы

## Закон 2: Закон Тени (Shadow)

**Суть:** У каждого есть тёмная сторона: подавленные желания, агрессия, зависть, страх. Она скрыта, но под давлением выходит.

**Признаки активации Тени:**
- Внезапная агрессия/раздражение
- Иррациональные решения
- Проекция (обвиняет других в том, что есть в себе)
- Саботаж успеха (своего или чужого)

**Применение:**
- Знай свою Тень (признай её)
- Наблюдай Тень других (особенно в стрессе)
- Можешь провоцировать Тень врага, чтобы он ошибся

## Закон 3: Закон Роли (Persona)

**Суть:** Люди носят маски. Публичная персона ≠ реальный человек.

**Применение:**
- Не суди по маске — суди по поведению в стрессе
- Смотри, как человек относится к официантам, подчинённым
- Задержка = правда. Первая реакция часто настоящая, потом — маска

## Закон 4: Закон Зависти

**Суть:** Зависть — одна из самых сильных и скрытых эмоций. Люди редко признают её.

**Признаки скрытой зависти:**
- Чрезмерные похвалы (overcompensation)
- Микро-критика успехов
- Отстранение после твоего успеха
- «Радость» при твоих неудачах (скрытая)

**Защита:**
- Не хвались успехами
- Приписывай успех удаче, не таланту
- Дистанцируйся от завистников

## Закон 5: Закон Грандиозности

**Суть:** Успех надувает эго. Люди начинают верить, что они особенные и правила для них не писаны.

**Признаки:**
- «Это не для меня, а для обычных людей»
- Окружение только подтверждает
- Игнорирование обратной связи

**Защита:** Держи рядом человека, который скажет правду.

## Закон 6: Закон Принадлежности

**Суть:** Люди определяют себя через группы. Атака на группу = атака на идентичность.

**Применение:**
- Определи, с какими группами человек идентифицируется
- Не атакуй группу — атакуй идею
- Можно использовать «мы-фрейминг» для союзничества

# МОДЕЛЬ «АЙСБЕРГ» (глубинный анализ)

```
        [ПОВЕДЕНИЕ] — что человек делает/говорит
            ↓
        [ЭМОЦИЯ] — что чувствует
            ↓
        [ПОТРЕБНОСТЬ] — чего на самом деле хочет
            ↓
        [УБЕЖДЕНИЕ] — какая картина мира это создаёт
            ↓
        [ОПЫТ/ТРАВМА] — откуда это убеждение
```

**Пример:**
```
Поведение: Кричит на подчинённых
Эмоция: Страх
Потребность: Контроль, безопасность
Убеждение: «Если не контролировать, всё развалится»
Опыт: Хаотичное детство / предыдущий провал
```

# ЧТЕНИЕ НЕВЕРБАЛИКИ

## Базовые индикаторы

| Сигнал | Интерпретация |
|:-------|:--------------|
| Скрещенные руки | Защита (но может быть привычка — смотри контекст) |
| Отклонение назад | Дистанцирование, несогласие |
| Наклон вперёд | Интерес, вовлечённость |
| Прикрытие рта | Скрывает что-то / неуверенность |
| Прикосновение к носу | Дискомфорт, возможно ложь |
| Ноги к выходу | Хочет уйти |
| Зеркалит тебя | Раппорт, симпатия |
| Прерывистый контакт глаз | Дискомфорт |
| Слишком много контакта | Желание доминировать / манипулировать |

## Правила интерпретации

1. **Контекст важнее сигнала:** Человек может скрестить руки, потому что холодно
2. **Ищи кластеры:** Один сигнал ничего не значит, три — паттерн
3. **Baseline:** Сначала изучи «норму» человека, потом смотри отклонения
4. **Изменения:** Важно не положение, а изменение. Был расслаблен — напрягся = триггер

# ТИПОЛОГИЯ МОТИВАЦИЙ

## Модель 4 базовых потребностей

| Потребность | Проявления | Как работать |
|:------------|:-----------|:-------------|
| **Признание** | Хочет похвалы, статуса, респекта | Признавай вклад, давай статусные роли |
| **Контроль** | Хочет предсказуемости, власти | Давай выбор, прозрачность, полномочия |
| **Безопасность** | Боится рисков, перемен | Снижай неопределённость, давай гарантии |
| **Принадлежность** | Хочет быть частью группы | «Мы», командные ритуалы, inclusion |

## Определение ведущей потребности

**Вопросы:**
- Чего этот человек боится больше всего?
- Что его злит?
- Чем он хвастается?
- На что жалуется?

# РАБОТА С ТЕНЬЮ (Shadow Work)

## Для себя

1. **Признай:** «Во мне есть [зависть/злость/страх/...]»
2. **Не подавляй:** Подавленное возвращается в худшей форме
3. **Исследуй:** «Когда это началось? Что триггерит?»
4. **Интегрируй:** «Эта часть меня хочет [X]. Как дать ей это здоровым способом?»

## Для чтения других

- Под стрессом Тень выходит — наблюдай кризисы
- То, что человек резко осуждает в других, часто есть в нём
- Повторяющиеся конфликты = проекция

# ВЛИЯНИЕ И УБЕЖДЕНИЕ

## 6 Принципов влияния (Cialdini)

| Принцип | Как работает | Пример |
|:--------|:-------------|:-------|
| **Взаимность** | Люди возвращают услуги | Сделай что-то первым |
| **Обязательство** | Люди хотят быть последовательными | Маленькое «да» → большое «да» |
| **Социальное доказательство** | «Все так делают» | Покажи, что другие выбрали это |
| **Симпатия** | Говорим «да» тем, кто нравится | Найди общее, будь обаятелен |
| **Авторитет** | Подчиняемся экспертам | Демонстрируй компетентность |
| **Дефицит** | Редкое ценнее | Ограничь доступ/время |

## Фрейминг

Как подать информацию важнее, чем сама информация.

| Фрейм | Пример |
|:------|:-------|
| **Потеря vs Выигрыш** | «Вы теряете 10% без этого» > «Вы выиграете 10%» |
| **Мы vs Он** | «Мы вместе» > «Я тебе предлагаю» |
| **История vs Факты** | Одна история > десять статистик |

# ЗАЩИТА ОТ МАНИПУЛЯЦИЙ

## Красные флаги

- Давление через срочность («только сейчас»)
- Изоляция от других мнений
- Апелляция к эмоциям вместо фактов
- Слишком хорошо, чтобы быть правдой
- Уход от прямых ответов
- Переход на личности вместо аргументов

## Противодействие

1. **Замедлись:** «Мне нужно время подумать»
2. **Проверь факты:** Не верь на слово
3. **Спроси «почему»:** Манипуляторы не любят глубоких вопросов
4. **Обратись к третьей стороне:** Внешний взгляд
5. **Назови игру:** «Это звучит как давление через срочность»
