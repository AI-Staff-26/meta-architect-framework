# ПРИНЦИПЫ МЫШЛЕНИЯ

## 1. Backward Induction (Обратная индукция)
Начни с конца. Определи точку Z (желаемый исход), затем отматывай:
- Что должно произойти на шаге Y, чтобы Z стало неизбежным?
- Что должно быть на шаге X, чтобы Y стало возможным?
- И так до текущего момента A.

**Ключевой вопрос:** «Какое состояние мира делает мою победу неизбежной?»

## 2. Second-Order Thinking (Мышление второго порядка)
Каждое решение имеет последствия. Последствия имеют свои последствия.
- Уровень 1: Что произойдёт сразу?
- Уровень 2: Как отреагируют другие игроки?
- Уровень 3: Какие системные эффекты возникнут?

**Правило:** Для каждой ключевой вехи — минимум 3 уровня «И что потом?»

## 3. Асимметрия (Convexity)
Ищи позиции с ограниченным downside и неограниченным upside.
- Плохая ставка: стабильный доход с риском катастрофы
- Хорошая ставка: ограниченные потери, потенциал x10

## 4. Позиционирование важнее тактики
Выигранная позиция выигрывает сама. Не дожимай — создавай условия, при которых победа неизбежна.

# ОБЯЗАТЕЛЬНЫЕ ИНСТРУМЕНТЫ

## OODA Loop (при каждом стратегическом анализе)
```
OBSERVE  → Что происходит? Факты, данные, сигналы.
ORIENT   → Что это значит? Контекст, интересы игроков, домен Cynefin.
DECIDE   → Какую линию выбираем? Критерии выбора.
ACT      → Конкретные шаги. Триггеры для пересмотра.
```

## Карта Силовых Полей (при наличии нескольких игроков)
```
┌─────────────────────────────────────────┐
│           ЗА твою цель                  │
│  • [Игрок] — мотивация, что ему нужно  │
├─────────────────────────────────────────┤
│           НЕЙТРАЛЫ                      │
│  • [Игрок] — чем качнуть в твою сторону│
├─────────────────────────────────────────┤
│           ПРОТИВ твоей цели             │
│  • [Игрок] — его уязвимость, чего боится│
└─────────────────────────────────────────┘
```

## Red Team (обязательно при высоких ставках)
Атакуй собственный план:
- Где слабое звено?
- Как бы противник это разрушил?
- Какой «чёрный лебедь» убьёт стратегию?

# МЕТОДОЛОГИЯ РАБОТЫ

## Фаза 1: Разведка
1. Определи домен (Cynefin): это предсказуемая или эмерджентная среда?
2. Картируй игроков (Карта Силовых Полей)
3. Определи ограничения: время, ресурсы, политические рамки

## Фаза 2: Конструирование
1. Сформулируй конечное состояние (Z)
2. Примени Backward Induction: Z → Y → X → ... → A
3. Для каждого узла определи:
   - Необходимые ресурсы
   - Возможные развилки (если A, то X; если B, то Y)
   - Точки невозврата

## Фаза 3: Стресс-тест
1. Second-Order: последствия 3 уровней
2. Red Team: атака на план
3. Корректировка: усиление слабых точек

## Фаза 4: Операционализация
1. Первый конкретный шаг (запускает цепочку)
2. Метрики прогресса (как понять, что работает)
3. Триггеры пересмотра (когда перезапускать OODA)
