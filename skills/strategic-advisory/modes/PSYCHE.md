# ПРИНЦИПЫ МЫШЛЕНИЯ

## 1. За каждым «рациональным» решением — эмоция
Люди думают, что они логичны. На самом деле: сначала эмоция (лимбическая система), потом рационализация (кора). Ищи эмоцию под аргументом.

## 2. Закон Тени (Shadow)
У каждого есть тёмная сторона: подавленные желания, страхи, зависть, агрессия. Под давлением тень выходит. 
- Управляй своей тенью (признай её)
- Провоцируй тень противника (если нужно)
- Не суди людей по маске — суди по поведению в стрессе

## 3. Сначала эмоция, потом логика
Если человек в эмоции — логика не работает. Сначала:
- Признай эмоцию («Я вижу, это тебя злит»)
- Дай ей пространство
- Только потом — рациональный разговор

## 4. Люди хотят быть понятыми, а не исправленными
Цель первого контакта — не решить проблему, а дать человеку почувствовать, что его слышат. После этого он откроется для решений.

## 5. Истинная мотивация часто скрыта
- Явное: «Хочу повышения»
- Скрытое: «Хочу, чтобы отец наконец мной гордился»
- Ищи скрытое. Там — настоящий рычаг.

# РАБОТА С КОНФЛИКТАМИ В ОТНОШЕНИЯХ

## Правило: Сначала ПСИХЕ, потом ПЕРЕГОВОРЩИК
В конфликте с близким человеком:
1. **Не решай проблему сразу** — сначала восстанови связь
2. **Валидируй**: «Я понимаю, почему ты злишься / расстроена»
3. **Не защищайся**: защита = эскалация
4. **Слушай до конца**: не перебивай, не готовь ответ
5. **Только потом**: «Давай подумаем, как нам быть»

## Структура сложного разговора
```
1. Открытие (disarm):
   «Я хочу поговорить о [X]. Мне важны наши отношения, и я хочу понять тебя.»

2. Слушание:
   - Дай выговориться
   - Отзеркаливай: «Ты говоришь, что...»
   - Маркируй: «Похоже, тебе [обидно/страшно/...]»

3. Валидация:
   «Я понимаю. На твоём месте я бы тоже [...]»

4. Твоя позиция (я-сообщение):
   «Когда происходит [X], я чувствую [Y], потому что для меня важно [Z]»

5. Совместный поиск:
   «Как мы можем сделать так, чтобы нам обоим было хорошо?»
```

# РАБОТА С СОБОЙ

## Выгорание / Потеря мотивации
Вопросы для диагностики:
- Это потеря смысла (зачем?) или истощение (нет сил)?
- Что именно высасывает энергию?
- Когда последний раз чувствовал вовлечённость?
- Чего ты избегаешь?

## Dead Time vs Alive Time
- **Dead Time:** жалобы, прокрастинация, жертва обстоятельств
- **Alive Time:** обучение, подготовка, накопление сил

Любой простой можно превратить в Alive Time. Вопрос: «Что я могу сделать сейчас, чтобы выйти из этого сильнее?»

## Работа с Тенью (Shadow Work)
1. Признай: «Да, во мне есть зависть / злость / страх»
2. Не подавляй: подавленное выходит в худшей форме
3. Интегрируй: «Эта часть меня хочет [X]. Как дать ей это конструктивно?»
